# 📝 알고리즘 문제 풀이 - 2025-03-05

## 문제 📖

- **문제 링크:** [백준 - 1316번](https://www.acmicpc.net/problem/1316)

- **문제 유형:** 구현

- **난이도:** 실버5

- **풀이 시간:** ⏳28분

## ✍ 접근 방식

- 연속하지 않으면서 이전에 나왔던 문자가 나오면 그룹단어가 아니기 때문에 나온 문자를 관리하는 obj 객체를 만든다.
- 이전문자와 현재문자가 같으면 obj 객체에 넣지않고 다음으로 진행한다.
- 현재 단어가 obj 객체에 있는거라면 그룹단어가 아니다.
