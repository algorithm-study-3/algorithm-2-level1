# 📝 알고리즘 문제 풀이 - 2025-03-30

## 문제 📖

- **문제 링크:** [백준 - 1697번](https://www.acmicpc.net/problem/1697)

- **문제 유형:** 그래프 탐색

- **난이도:** 실버1

- **풀이 시간:** ⏳30분

## ✍ 접근 방식

- 현재 위치에서 -1, +1, \*2를 하는 경우를 나눠서 그래프 탐색처럼 할 수 있을 거 같아서 dfs, bfs를 생각했다.
- 가장 빠른 시간을 출력하는 것이라 bfs를 선택했다.
- 수빈이의 위치와 동생의 위치중 더 먼곳 * max + 1을 해줘서 max값을 정해줬다. (*2까지 갈 수 있으니 이렇게 지정)
- 이동가능한 위치이면 계속 bfs순회를 시키면서 count+1을 한다. 동생의 위치에 도달하면 count를 정답으로 출력한다.
