# 📝 알고리즘 문제 풀이 - 2025-03-30

## 문제 📖

- **문제 링크:** [백준 - 11724번](https://www.acmicpc.net/problem/11724)

- **문제 유형:** 그래프 탐색

- **난이도:** 실버2

- **풀이 시간:** ⏳ 20분

## ✍ 접근 방식

- 연결 요소를 구해야 하므로 이어져 있는 것들을 먼저 찾으려 했다.
- 이어진 것들을 끝까지 돌기 위해 dfs를 선택했다.
- 해당 간선을 다 돌아야 하므로 방문하지 않았으면서, 0보다 크거나 n보다 같거나 작을때 순회를 계속 하도록 했다.
- dfs를 한번 돌때마다 연결 요소 하나라고 간주하고 answer+1을 한다.
