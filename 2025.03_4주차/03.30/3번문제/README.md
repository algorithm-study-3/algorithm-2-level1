# 📝 알고리즘 문제 풀이 - 2025-03-30

## 문제 📖

- **문제 링크:** [백준 - 10816번](https://www.acmicpc.net/problem/10816)

- **문제 유형:** 이분탐색, 자료구조, 해시를 사용한 집합과 맵

- **난이도:** 실버4

- **풀이 시간:** ⏳ 62분

## ✍ 접근 방식

방법1

- 숫자가 커서 이분탐색을 시도하려했다.
- 숫자를 찾기만 하는 것이 아니라 몇번 나왔는지 알아야 해서 정렬후 해당 숫자가 처음 나오는 인덱스와 해당 숫자가 아니게된 인덱스를 구해서 그둘의 차이를 카드가 나온 개수로 친다.

방법2

- 원래 있던 거를 카운트만 하면 되어서 객체나 Map자료구조를 사용하면 된다 판단
- 상근이가 몇 개 가지고 있는 숫자 카드인지 구해야할 카드들을 map객체에 넣고, 상근이가 가진 카드들 중에서 있다면 value값을 +1 한다.
