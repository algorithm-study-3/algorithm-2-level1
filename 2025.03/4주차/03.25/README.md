# 📝 알고리즘 문제 풀이 - 2025-03-25

## 문제 📖

-   **문제 링크:** [백준 - 저항](https://www.acmicpc.net/problem/1076)

-   **문제 유형:** `구현`

-   **난이도:** 브론즈 2

-   **풀이 시간:** ⏳ 20분 - 실제 걸렸던 시간

## ✍ 접근 방식

1. 저항 표, 정답, 저항 값을 초기화한다.
2. colors를 순회하면 인덱스 번호가 0이나 1일 경우 저항값에 string으로 추가한다.
3. 마지막 값을 기존 저항 값에 곱하고 answer에 넣어준다.
4. answer를 반환한다.
