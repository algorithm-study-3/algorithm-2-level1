## 문제 📖

-   **문제 링크:** [리트코드 - Missing Number](https://leetcode.com/problems/missing-number/description/)

-   **문제 유형:** `Array`, `Hash Table`, `Math`, `Binary Search`, `Bit Manipulation`, `Sorting`

-   **난이도:** EASY

-   **풀이 시간:** ⏳ 4분 - 실제 걸렸던 시간

## ✍ 접근 방식

1. nums 길이만큼 0부터 n까지 배열을 만들고 reduce로 더해준다.
2. nums에 있는 숫자를 reduce로 더해준다.
3. 두 숫자를 빼주어 빠진 숫자를 알아낸다.
