# 📝 알고리즘 문제 풀이 - 2025-03-19

## 문제 📖

-   **문제 링크:** [프로그래머스 - 구명보트](https://school.programmers.co.kr/learn/courses/30/lessons/42885)

-   **문제 유형:** `Greedy`

-   **난이도:** LV.2

-   **풀이 시간:** ⏳ 30분 - 실제 걸렸던 시간

## ✍ 접근 방식

1. 무게가 무거운 순서대로 정렬한다.
2. 마지막 인덱스와 첫번째 인덱스를 초기화한다.
3. 마지막 인덱스가 첫번째 인덱스보다 크거나 작을 때까지 반복을 한다.
4. 첫번째 사람과 마지막 사람을 더한 것이 limit를 넘는지 확인하고 넘지 않을 경우 마지막 인덱스를 하나 줄인다.
5. 첫번째 인덱스를 +1 증가하고 정답을 +1 증가한다.
6. 답을 반환한다.
