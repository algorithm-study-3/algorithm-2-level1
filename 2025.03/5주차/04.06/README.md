# 📝 알고리즘 문제 풀이 - 2025-04-06

## 문제 📖

-   **문제 링크:** [백준 - ATM](https://www.acmicpc.net/problem/11399)

-   **문제 유형:** `그리디`

-   **난이도:** 실버 4

-   **풀이 시간:** ⏳ 10분 - 실제 걸렸던 시간

## ✍ 접근 방식

1. 대기 시간을 0으로 초기화 해준다.
2. 사람들의 인출 시간을 기준으로 오름차 순 정렬을 한다.
3. 정렬된 배열을 순회하면서 값과 대기시간을 더해준다. (대기 시간도 포함)
4. 다 더해진 시간을 출력한다.
