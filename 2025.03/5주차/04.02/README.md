# 📝 알고리즘 문제 풀이 - 2025-04-02

## 문제 📖

-   **문제 링크:** [백준 - 경로당펑크 2077](https://www.acmicpc.net/problem/25205)

-   **문제 유형:** `구현`

-   **난이도:** 브론즈 2

-   **풀이 시간:** ⏳ 15분 - 실제 걸렸던 시간

## ✍ 접근 방식

1. consonants를 선언하고 자음을 배열로 초기화한다.
2. 문자열에 마지막 요소가 자음에 포함이 되는지를 확인하고 포함되지 않았을 경우 0 포함되었을 경우 1을 출력한다.
