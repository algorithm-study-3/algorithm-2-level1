# 📝 알고리즘 문제 풀이 - 2025-03-23

## 문제 📖

- **문제 링크:** [백준 - 진짜 공간](https://www.acmicpc.net/problem/1350)

- **문제 유형:** 수학, 사칙연산

- **난이도:** 브론즈2

- **풀이 시간:** ⏳ 7분

## ✍ 접근 방식
- 모든 파일을 순회하면서 필요한 클러스터의 개수를 구한다.
    - 파일의 크기가 0이면 클러스터가 필요하지 않다.
    - 파일 크기가 클러스터의 크기보다 작거나 같으면 한 개가 필요하다.
    - 파일 크기가 클러스터의 크기보다 큰 경우
        - 나머지가 없다면 몫 만큼의 개수가 필요하다.
        - 나머지가 있다면 몫 + 1 만큼의 개수가 필요하다.
