# 📝 알고리즘 문제 풀이 - 2025-03-24

## 문제 📖

-   **문제 링크:** [프로그래머스 - 옹알이](https://school.programmers.co.kr/learn/courses/30/lessons/120956)

-   **문제 유형:** `String`

-   **난이도:** Lv.0

-   **풀이 시간:** ⏳ 30분 - 실제 걸렸던 시간

## ✍ 접근 방식

1. 아기가 말할 수 있는 발음들을 배열로 초기화한다.s
2. 주어진 단어들을 순회한다.
3. 말할 수 있는 단어들을 반복하면서 주어진 단어의 중복되는 값을 z로 변경한다.
4. 마지막으로 z를 제외하고 문자열의 길이를 확인한다.
5. 길이가 0일 경우 answer를 + 1 한다.
6. 정답을 반환한다.
