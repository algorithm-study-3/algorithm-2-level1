# 📝 알고리즘 문제 풀이 - 2025-03-23

## 문제 📖

-   **문제 링크:** [리트코드 - Roman to Integer](https://leetcode.com/problems/roman-to-integer/description/)

-   **문제 유형:** `Math`

-   **난이도:** Easy

-   **풀이 시간:** ⏳ 13분 - 실제 걸렸던 시간

## ✍ 접근 방식

1. 문자열을 나누어 배열로 만든다.
2. 로마 숫자 심볼을 객체로 초기화한다.
3. 단어의 길이만큼 순회한다.
4. 다음 문자가 현재 문자와 같은 경우, 현재 문자가 더 클 경우, 다음 문자가 undefined인 경우 현재 문자만큼 answer에 더해준다.
5. 다음 문자가 현재 문자보다 클 경우 다음 문자 - 현재 문자를 answer에 더해주고 i를 하나 더한다.
6. 정답을 반환한다.
