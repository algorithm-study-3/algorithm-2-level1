# 📝 알고리즘 문제 풀이 - 2025-03-23

## 문제 📖

-   **문제 링크:** [리트코드 - Longest Common Prefix](https://leetcode.com/problems/longest-common-prefix/description/)

-   **문제 유형:** `Math`

-   **난이도:** Easy

-   **풀이 시간:** ⏳ 18분 - 실제 걸렸던 시간

## ✍ 접근 방식

1. prefix를 초기화한다.
2. 반복하는 횟수를 줄이기 위해 문자열의 길이대로 정렬을 한다.
3. 첫번째 문자를 정렬된 배열에서 제거하면서 가지고 온다.
4. 정렬된 배열이 비어있을 경우 첫번째 문자를 출력한다.
5. 두번째 문자열을 정렬된 배열에서 제거하면서 가지고 온다.
6. 첫번째와 두번째 문자열에서 반복되는 부분을 prefix에 추가한다.
7. 정렬된 배열에 남아있는 문자열을 하나씩 꺼내오면서 prefix에 길이만큼 반복한다.
8. prefix와 word의 각 문자열들을 비교하면서 다른 경우 prefix를 공통되는 부분을 제외한 나머지 부분을 제거한다.
9. 만약 prefix의 문자열 길이가 0일 경우 반복문을 멈춘다.
10. 반복문이 종료되고 prefix를 반환한다.
