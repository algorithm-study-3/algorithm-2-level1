# 📝 알고리즘 문제 풀이 - 2025-03-23

## 문제 📖

- **문제 링크:** [leetcode - two-sum](https://leetcode.com/problems/two-sum/)

- **문제 유형:** (배열)

- **난이도:** (예: easy)

- **풀이 시간:** ⏳ (5분)

## ✍ 접근 방식

- 이중 for문을 활용
- 바깥 반복문은 0에서 배열의 길이 -1
- 안쪽 반복문은 1에서 배열의 길이까지 순회
- 반복문을 돌면서 i + j의 합이 target이면 [i, j]를 반환한다.
