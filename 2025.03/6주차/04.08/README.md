# 📝 알고리즘 문제 풀이 - 2025-04-08

## 문제 📖

-   **문제 링크:** [프로그래머스 - 저주의 숫자 3](https://school.programmers.co.kr/learn/courses/30/lessons/120871)

-   **문제 유형:** `구현`

-   **난이도:** Lv. 0

-   **풀이 시간:** ⏳ 40분 - 실제 걸렸던 시간

## ✍ 접근 방식

1. n까지 반복을 하며 answer를 더한다.
2. 기본적으로 1을 더한다.
3. 더한 값에 3이 있는 경우 2가지 조건으로 나뉜다.
4. 길이가 2일 경우 첫번째 자리가 3인 경우와 길이가 3일 경우 두번째 길이가 3인 경우는 10을 더한다.
5. 그것이 아닐 경우는 1을 더한다.
6. 더한 값이 3의 배수일 경우 다시 1을 더한다.
7. 3번을 다시 한 번 실행한다.
8. 정답을 반환한다.
